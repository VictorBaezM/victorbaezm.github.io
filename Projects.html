1st-Semester-2022-CTFs

A collection of all CTF problems attempted/completed during the course of my studies in the University of Puerto Rico Mayaguez. CTFs or "Capture The Flag" exercises are coding problems that are designed to test whether a participant can find a specific string that is hidden within a medium. This medium could be a bug that the developer needs to exploit, an image that the developer needs to find the source of or even a semi blind decoding of an encryption. There exist almost no limitations as to how these problems are created as long as you can generate a string from it. The best part of these problems is that they are meant to encourage the participant to think outside the box to solve them which is a good mindset to develop.

Kat Fight

Kat Fight is a game that was created as part of a group assignment for the video game design course from Georgia Tech. The purpose of the assignment was to get a feel of the game design process by working with the animations, logic and feel that would be present in the real world. We were tasked to generate an alpha, beta and then a final product. This video is meant to showcase the final product as well as give an idea of the different components implemented. It was created using the Unity engine along with github for version control.
